# dodo-lotto-data

로또 6/45 동반 앱 **도도로또**가 받는 공개 당첨번호 데이터(정적 JSON)입니다.

- **비공식 데이터입니다.** 이 저장소와 도도로또 앱은 동행복권·복권위원회와 무관합니다.
- **데이터 출처: 동행복권.** 앱에 필요한 필드(회차, 추첨일, 당첨번호, 등수별 당첨자 수·1인당 당첨금, 판매액, 1등 자동·수동·반자동 건수)만 담습니다.
- 당첨 여부는 반드시 공식 채널에서 최종 확인하세요.
- 파일 형식: `v1/` 아래 `latest.json`, `draws/{회차}.json`, `revisions.json`, `config.json`. 계약은 앱 저장소의 `docs/architecture/data-contract-v1.md` 를 따릅니다.
- 이 저장소는 자동 수집 파이프라인이 갱신합니다. 직접 커밋하지 않습니다.
